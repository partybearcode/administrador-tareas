# Gestor de Tareas (Consola - Java)

Aplicación sencilla de consola para gestionar una lista de tareas.
Permite añadir tareas, listarlas, marcarlas como completadas y eliminarlas.

## Estructura del proyecto
- **Tarea.java**: Modelo de una tarea (descripción y estado de completada).
- **GestorTareas.java**: Lógica de gestión usando `ArrayList<Tarea>`.
- **Main.java**: Menú interactivo por consola.

## Funcionalidades
- Añadir tarea
- Listar tareas
- Marcar tarea como completada
- Eliminar tarea

## Generación de JavaDoc (NetBeans)
1. En NetBeans, clic derecho sobre el proyecto.
2. Selecciona **Generate Javadoc**.
3. Se creará la carpeta **javadoc** en la raíz del proyecto (sincronízala junto al resto del proyecto).
